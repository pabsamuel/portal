# Brand and Naming

Publisher: **Atesen Software**. Product name below is a working title until clearance is done.

| Candidate | Why | Risk |
|---|---|---|
| **Farwindow** (current working title) | “A window to far places”; fits ambient/TV use | Descriptive → weaker trademark |
| Riftcast | Portal + cast; good for the streamer/Pro tier | Many “Rift” products (Oculus Rift history) |
| Yonder Portal | Warm, family-friendly | “Yonder” widely used — check class 9 |
| Wayfold | “Fold space to a place”; ownable | Needs explaining |
| Glimmerdoor | Playful, kids/party | Long |

Shortlist: **Farwindow** (consumer) and **Riftcast** (streamer/Pro). Avoid anything with “ring”, “sorcerer”, “mystic”.

## Clearance checklist (~2 hours, do before V3 landing page)
USPTO search (classes 9, 41, 42) · EUIPO/TMview · WIPO Global Brand Database · TÜRKPATENT · names in App Store, Google
Play, Amazon Appstore, Chrome Web Store · domains (.com/.app/.tv) · handles on TikTok, Instagram, YouTube, X, Reddit ·
Google “<name> app”. Kill any name used by a live product in classes 9/41/42. File at TÜRKPATENT only after Revenue gate 1.

## Visual identity (as implemented)
- **Default theme “Kıvılcım / Ember”:** white-hot core → gold → orange → deep red sparks, grinder-style flung sparks,
  soft glow rim, dark vignette inside the portal. Deliberately *no* runes, glyphs or mandala patterns.
- Other themes: **Aurora** (cyan→violet), **Plazma** (pink→purple), **Buz / Frost** (white→blue). Consider making Aurora
  the default for the store version to put more distance from film imagery.
- Motion: a spark traces the circle in the direction you drew (0.34 s) → iris opens with a slight overshoot (0.66 s) →
  rim keeps spinning and breathing → hop = flare + shockwave → close = collapse into a spark burst.
- Sound: synthesized whoosh + low thump + crackle; hum while open (no audio files, no licensing).
- UI: dark, one system font, warm accent `#ffa334`, gold `#ffd875`.
- Logo idea: an open ring with a small gap (a doorway), in the theme gradient.
